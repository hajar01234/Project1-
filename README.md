# Project Name: Pizza Memory

## Technologies Used
* HTML 
* CSS
* JavaScript 


## Description
Pizza Memory is a memory game where players need to remember pizza toppings and their positions. The game has two modes: Single Player and Two Players.

In Single Player mode, the player can choose between three difficulty levels: Easy, Medium, and Hard. Each level has a different number of toppings and a time limit. The player needs to remember the pizza and place the toppings in the correct positions before the time runs out. The player can also ring a bell to finish early.

In Two Players mode, players take turns using the same laptop. Each player gets a different pizza to remember.

Players earn 1 point for choosing the correct topping in the wrong position and 2 points for placing the correct topping in the correct position. When a player reaches 10 points, a pop-up appears with options to play again or exit. In Single Player mode, the player can also move to the next level if one is available.


## User Stories
* As a user, I want to choose between Single Player and Two Players mode so that I can play alone or with a friend.

* As a user, I want to choose a difficulty level so that I can play at my own level.

* As a user, I want to see a pizza with different toppings so that I can memorize them.

* As a user, I want to place toppings on my pizza so that I can recreate the original pizza.

* As a user, I want to see a timer so that I know how much time I have left.

* As a user, I want to ring a bell when I finish so that I can end my turn early.

* As a user, I want to earn points for correct toppings and positions so that I can track my progress.

* As a user, I want to see my score so that I know how close I am to winning. 

* As a user, I want to see a winning pop-up when I reach 10 points so that I know I have won.

* As a user, I want to play again or exit the game so that I can choose what to do next.

* As a user, I want to move to the next level when available so that I can try a harder challenge.
